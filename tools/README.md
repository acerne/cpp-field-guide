# Tools

> Practical reference for C++ development tools — formatters, static analyzers, testing frameworks, and benchmarking.

## Code Quality

- [clang-format](clang-format.md) — enforce consistent code style automatically
- [clang-tidy](clang-tidy.md) — static analysis and modernization checks with auto-fix support

## Testing

- [GoogleTest](googletest.md) — Google's C++ unit testing framework
- [Catch2](catch2.md) — expressive testing framework with natural-language syntax; an alternative to GoogleTest

## Benchmarking

- [Google Benchmark](google-benchmark.md) — microbenchmarking library for measuring C++ code performance

## Online Tools

- [OnlineGDB](onlinegdb.md) — browser-based compiler and debugger for quick tests and sharing snippets
- [Compiler Explorer](compiler-explorer.md) — shows annotated assembly for C++ code across multiple compilers and optimization levels
- [Quick-Bench](quick-bench.md) — browser-based microbenchmarking built on Google Benchmark; compares variants without local setup
