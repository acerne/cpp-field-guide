# OnlineGDB

> Browser-based C++ compiler and debugger for quick tests and sharing self-contained snippets.

[onlinegdb.com](https://www.onlinegdb.com/)

---

## Overview

OnlineGDB runs C++ code in the browser with no setup. The built-in debugger supports breakpoints and step-through execution, making it useful beyond simple compile checks.

Key capabilities:
- Select C++ standard (C++14, C++17, C++20)
- Step-through debugger with breakpoints and variable inspection
- stdin support for programs that read input
- Shareable links for snippets

---

## When to Use

Good for quickly testing a snippet, reproducing a bug to share with others, or debugging small self-contained programs. For assembly output or performance comparisons, use [Compiler Explorer](compiler-explorer.md) or [Quick-Bench](quick-bench.md) instead.
